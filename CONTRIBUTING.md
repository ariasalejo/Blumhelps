# Contributing

1. Check existing issues before starting substantial work.
2. Create a focused branch and keep pull requests reviewable.
3. Run the debug build with JDK 17, Android SDK, and compatible Gradle.
4. Include tests or manual verification steps; never claim tests passed if they were not run.
5. Update documentation when behavior changes.

Request the fewest permissions possible. Never commit credentials, private user data, or unredacted support conversations. New telemetry, network access, and data collection require a documented purpose and privacy review.
